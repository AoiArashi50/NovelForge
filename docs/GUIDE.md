# NovelForge 使用指南

## 1. 小说管理

### 添加小说
- **手动创建**：填写标题和作者，不上传文件（适合后续粘贴内容）
- **单文件上传**：选择 txt/docx/pdf 文件，填写标题和作者后点击"上传并解析"
- **批量上传**：文件选择框支持 `Ctrl/Cmd + 点击` 多选多个文件，系统会用文件名作为默认标题逐一解析

### 小说操作
- 点击小说卡片进入**阅读器**
- **开始翻译**：下拉菜单选择翻译风格（直译/意译/文学性），填写自定义要求后开始。上次使用的风格和提示词会自动记忆
- **导出翻译**：支持纯中文模式或原文+译文对照模式
- **索引到 RAG**：将已翻译的小说内容加入向量数据库，供后续翻译和二创时检索参考
- **编辑标签**：为小说打标签分类

---

## 2. 翻译

### 翻译流程
1. 在小说管理页面点击小说的"开始翻译"
2. 选择**翻译风格**：
   - **直译**：保留原文结构和语序
   - **意译**：让译文自然流畅，符合中文表达习惯
   - **文学性**：注重文采和意境，适合小说翻译
3. 填写**自定义要求**（可选）：如"保持原文段落结构""使用古风表达""人名统一译为..."
4. 点击"开始翻译"，系统会逐章翻译并保存结果

### 翻译记忆
- 系统会自动利用已索引的平行语料（素材池中的原文+译文对照）来提升术语和风格一致性
- 首次翻译某系列前，建议先在素材池中上传该系列的平行语料并索引

---

## 3. 阅读器

### 阅读模式
- 点击小说卡片进入阅读器
- 支持**单语模式**（仅译文）和**双语对照模式**（原文+译文并排）

### 个性化设置
点击右下角的设置图标：
- **主题**：暗黑 / 羊皮纸 / 明亮 / OLED 纯黑
- **字体**：衬线体 / 无衬线体 / 等宽体
- **排版**：行高、段间距、页边距、布局模式

### 高亮批注
1. 选中任意文本段落
2. 在弹出的批注面板中选择颜色并填写批注内容
3. 批注会保存到数据库，下次打开时自动恢复高亮显示
4. 右侧批注列表可查看和管理所有批注

---

## 4. 世界观库（Lore Library）

### 系列管理
- 创建系列/世界观组，如"斗破苍穹""哈利波特"
- 每个系列下管理角色卡、世界观设定、正史事件

### 角色卡
- 填写角色名称、别名、年龄、外貌标签、性格特质、核心动机、人际关系、语言风格、禁忌等
- 这些信息会在 AI 二创时自动注入系统提示词，确保角色不 OOC

### 世界观设定
- 地理环境、力量体系/魔法系统、技术水平、文化习俗

### 正史事件
- 记录不可变事件（如"萧炎三年之约击败纳兰嫣然"）
- 标记为"不可变"的事件在二创时会被 AI 严格遵守
- 可选标记为"可变"，允许 AI 在此基础上延伸发挥

---

## 5. 素材池

### 素材类型
| 类型 | 用途 |
|------|------|
| **平行语料** | 原文+译文对照，用于翻译风格学习和术语一致性 |
| **参考小说** | 同系列/同题材参考作品，用于风格模仿 |
| **知识文档** | 设定集、世界观笔记、角色设定等 |

### 上传方式
- **双文件对齐**：分别粘贴原文和译文，点击"预览对齐"查看段落配对结果，可删除不匹配项或交换原文/译文，确认后保存
- **单文件/粘贴**：直接粘贴内容，适合知识文档或参考小说

### 索引
- 上传后素材状态为"待索引"
- 点击素材卡片上的 ✨ 按钮开始索引，系统会将内容切分为 chunks 并生成向量嵌入
- 已索引的素材才能被翻译和二创时的 RAG 检索使用

## 6. 二创工作室（Studio）

### AI 创作流程
1. **选择系列**：必选，系统会自动加载该系列的角色卡和世界观设定
2. **关联原作**（可选）：选择一本已上传的小说，AI 会参考其风格
3. **素材作用域**：
   - 勾选"包含素材池中的投喂素材"启用 RAG
   - 下方会列出该系列所有已索引素材，可**精确勾选**需要参考的素材
4. 填写**创作要求**（Brief）：描述你想写的内容
5. 填写**自定义系统提示词**（可选）：优先级最高，如"模仿金庸风格，多用环境描写"
6. 调整**生成参数**：
   - **创造力**：越高输出越发散有创意
   - **风格忠实度**：对原作写作风格的模仿程度
   - **角色忠诚度**：对角色设定卡的遵守严格程度
   - **氛围**：黑暗/浪漫/紧张/日常/悬疑/史诗
   - **长度**：短场景（500-1000字）/ 完整章（2000-4000字）/ 故事线大纲
   - **正史约束**：严格（遵守不可变事件）/ 宽松 / AU（平行宇宙）
7. 点击"开始创作"

### 续写
- 生成内容后，点击底部"续写"按钮，AI 会基于已有内容继续创作

### 段落重写
- 鼠标悬停在任意段落上，点击右侧的 🔄 按钮
- 输入重写要求，如"增加更多心理描写""让语气更严肃"
- AI 会替换该段落，其余内容保持不变

### 段落锁定
- 点击段落上的 🔒 按钮锁定该段落
- 锁定状态会在视觉上标记，方便你标识定稿内容

## 7. 工作流建议

### 翻译工作流
1. 在**素材池**上传平行语料（原文+译文）→ 索引
2. 在**小说管理**上传待翻译小说 → 开始翻译（选择意译/文学性风格）
3. 在**阅读器**审阅翻译结果，使用高亮批注标记需要修改的地方
4. 导出最终译文

### 二创工作流
1. 在**世界观库**建立系列、角色卡、世界观设定、正史事件
2. 在**素材池**上传参考小说/知识文档 → 索引
3. 在**二创工作室**选择系列、关联原作、勾选素材、填写创作要求
4. 生成后使用续写和段落重写精修内容
5. 保存或导出作品

---

## 8. 注意事项

- **素材必须先索引**：未索引的素材不会被 RAG 检索到
- **系列是核心**：二创时必须选择系列，角色卡和世界观才会被注入
- **翻译风格自动记忆**：每本小说独立记忆上次使用的风格和提示词
- **全文检索是补充**：混合 RAG 同时使用向量语义检索和关键词全文检索，确保专有名词也能被命中
